# Contributing

Thanks for your interest! Ideas, bug reports and improvements are welcome.

## Ways to help

- Report a bug or something confusing in the docs
- Suggest a new feature (more commodities, email alerts, charts)
- Improve the setup guide

## How to contribute

1. **Open an issue** first to describe the problem or idea.
2. **Fork** the repo and create a branch (`git checkout -b my-change`).
3. Make your change. If you edit the workflow:
   - Export it from n8n.
   - **Remove real sheet links, credential IDs and keys** before committing.
   - Keep `"active": false` or leave the activation off.
4. Update the README or setup guide if something changed.
5. Open a **pull request** and explain what you changed and why.

## Guidelines

- Keep language simple and clear.
- Test your change in n8n before submitting.
- Never commit secrets (API keys, tokens, passwords).
